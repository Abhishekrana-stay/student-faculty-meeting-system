# Student–Faculty Meeting Management System

A web-based application for managing meeting scheduling between students and faculty members.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Features
- Student and Faculty Authentication
- Role-Based Dashboards
- Meeting Request Management
- Accept/Reject Scheduling
- Alternate Time Suggestions
- Email Notifications using PHPMailer

## Tools Used
- XAMPP
- Git & GitHub
- VS Code
